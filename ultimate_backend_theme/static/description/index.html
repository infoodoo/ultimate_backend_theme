Installation

To install this theme:

  1. Download the module
  2. Extract the ZIP file to your Odoo addons directory
  3. Update your module list in Odoo
  4. Find and install the "Modern Business Theme" module

Customization

This theme offers extensive customization options:

  • Edit SCSS variables in static/src/scss/variables.scss to change colors, fonts, and spacing
  • Modify layouts in the XML view files under views/
  • Add custom JavaScript behaviors in static/src/js/
